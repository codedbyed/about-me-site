Renewal Online Reborn Reverse engineering and browser tooling

A reverse-engineering toolkit and browser-based game and spawn editor built from the shipped files of a 2003 traditional-Chinese game client. Every data format was decoded from the original binaries and each one is documented alongside the client function it was read from, so the findings are reproducible rather than guesswork.

The interesting constraint was separation of concerns: the disc's Chinese content is treated strictly as data and kept verbatim, while every string the tool renders is English. That keeps re-exporting safe, prevents a regeneration from clobbering a translation, and leaves the original text available as a fallback.

Breadboard Display Arduino Uno R3, embedded systems

A hardware display project on an Arduino Uno R3 driving both seven-segment numeric displays and a cluster of ST7735 TFT screens. Two daisy-chained 74HC595 shift registers handle the segment and digit lines, refreshed at 500Hz through a Timer2 interrupt, with the TFTs sharing the SPI bus.

It renders live Singapore weather from the Open-Meteo API with day/night-aware icon detection, alongside clock and system statistics, driven by a Python configuration layer that sets location, update intervals and serial port. Good practice of separating hardware mapping, display logic and configuration across the firmware and tooling.

Raspberry Pi homelab Infrastructure and operations

Self-hosted services and the operational tooling that keeps them running: Dockerised services including MediaFlow and a VPN client, dynamic DNS updates against a no-ip endpoint, and Wake-on-LAN scripts to bring hosts up on demand.

A small, unglamorous slice of infrastructure, but it is the same territory: repeatable configuration, monitoring by way of scripts, and services that are expected to come back on their own.

Brushie.sg Singapore e-commerce, live product

A live consumer brand selling smart oral care in Singapore. I built and run the site myself: a fast static front end with no framework and no backend, deployed on Apache behind a redirect that forces HTTPS and folds the www host onto the apex domain. Commerce runs through Lazada and Shopee rather than a direct checkout.

A small site, but it is a real business rather than a demo, and running one is a useful corrective to designing only inside large organisations.
